# Portfolio Make Guide

범용 포트폴리오 제작 가이드. 프로젝트 종류와 관계없이 일관된 시각 언어로 포트폴리오를 구성한다.

---

## 1. 기본 규격

### 슬라이드 크기
- **비율**: 16:9
- **해상도**: 1920 × 1080px
- **마진**: 48px (8px × 6)

### 그리드 시스템
```
┌─ 48px ───────────────────────────────────────────────────── 48px ─┐
│                                                                    │
│ 48px                                                          48px │
│                                                                    │
│  ┌──────────────────────────────────────────────────────────────┐ │
│  │                    Content Area                               │ │
│  │                    1824 × 984px                               │ │
│  └──────────────────────────────────────────────────────────────┘ │
│                                                                    │
│ 48px                                                          48px │
│                                                                    │
└─ 48px ───────────────────────────────────────────────────── 48px ─┘
```

### 간격 체계 (8px 배수)
| 토큰 | 값 | 용도 |
|------|-----|------|
| `--spacing-xs` | 8px | 텍스트 내 간격 |
| `--spacing-sm` | 16px | 요소 간 간격 |
| `--spacing-md` | 24px | 섹션 내 간격 |
| `--spacing-lg` | 32px | 주요 영역 간격 |
| `--spacing-xl` | 48px | 페이지 마진 |

## 2. 타이포그래피

### 서체
- **Primary**: Pretendard (한글), Inter (영문)
- **Monospace**: JetBrains Mono (코드)

### 토큰 정의
| 토큰 | 용도 | 크기 | 굵기 | Line Height |
|------|------|------|------|-------------|
| `--font-display` | 커버 메인 제목 | 72px | 700 | 1.1 |
| `--font-heading-1` | 페이지 제목 | 48px | 700 | 1.2 |
| `--font-heading-2` | 섹션 제목 | 36px | 600 | 1.25 |
| `--font-heading-3` | 소제목 | 28px | 600 | 1.3 |
| `--font-title` | 강조 텍스트 | 24px | 600 | 1.4 |
| `--font-body` | 본문 | 20px | 400 | 1.5 |
| `--font-body-sm` | 보조 본문 | 18px | 400 | 1.5 |
| `--font-caption` | 부가 설명 | 14px | 400 | 1.4 |
| `--font-label` | 태그/뱃지 | 12px | 500 | 1.2 |

### CSS 변수 정의
```css
:root {
  --font-display: 700 72px/1.1 'Pretendard', 'Inter', sans-serif;
  --font-heading-1: 700 48px/1.2 'Pretendard', 'Inter', sans-serif;
  --font-heading-2: 600 36px/1.25 'Pretendard', 'Inter', sans-serif;
  --font-heading-3: 600 28px/1.3 'Pretendard', 'Inter', sans-serif;
  --font-title: 600 24px/1.4 'Pretendard', 'Inter', sans-serif;
  --font-body: 400 20px/1.5 'Pretendard', 'Inter', sans-serif;
  --font-body-sm: 400 18px/1.5 'Pretendard', 'Inter', sans-serif;
  --font-caption: 400 14px/1.4 'Pretendard', 'Inter', sans-serif;
  --font-label: 500 12px/1.2 'Pretendard', 'Inter', sans-serif;
}
```

## 4. 레이아웃 템플릿

### 4.1 커버 페이지 (2컬럼)
```
┌──────────────────────────────────────────────────────────────────────────┐
│                                                                          │
│  ┌────────────────────────┐  ┌────────────────────────────────────────┐ │
│  │                        │  │ Label: 연도 · 프로젝트 유형            │ │
│  │                        │  │                                        │ │
│  │                        │  │ Display: 프로젝트 제목                 │ │
│  │      대표 이미지        │  │                                        │ │
│  │      (스크린샷)         │  │ Body: 프로젝트 한 줄 설명              │ │
│  │                        │  │                                        │ │
│  │                        │  ├────────────────────────────────────────┤ │
│  │                        │  │ 타임라인 또는 핵심 단계 (2열)          │ │
│  │                        │  ├────────────────────────────────────────┤ │
│  │                        │  │ 성과 그리드 (2×2)                      │ │
│  └────────────────────────┘  └────────────────────────────────────────┘ │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

**비율**: 좌 1 : 우 1.5
**용도**: 프로젝트 요약, 첫인상

---

### 4.2 텍스트 + 비주얼 (1:1)
```
┌──────────────────────────────────────────────────────────────────────────┐
│                                                                          │
│  Label: 섹션 카테고리                                                    │
│                                                                          │
│  Heading-1: 페이지 제목                                                  │
│                                                                          │
│  ┌─────────────────────────────┐  ┌─────────────────────────────────┐  │
│  │                             │  │                                 │  │
│  │  텍스트 콘텐츠              │  │  비주얼 콘텐츠                  │  │
│  │  (테이블, 목록, 설명)       │  │  (다이어그램, 스크린샷, 코드)  │  │
│  │                             │  │                                 │  │
│  └─────────────────────────────┘  └─────────────────────────────────┘  │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

**비율**: 1:1
**용도**: 문제 정의, 비교 설명

### 4.5 상하 분할 (1:1 + 플로우)
```
┌──────────────────────────────────────────────────────────────────────────┐
│                                                                          │
│  Label: 섹션 카테고리                                                    │
│                                                                          │
│  Heading-1: 페이지 제목                                                  │
│                                                                          │
│  ┌─────────────────────────────┐  ┌─────────────────────────────────┐  │
│  │  좌측 콘텐츠 (Why)          │  │  우측 콘텐츠 (How)              │  │
│  └─────────────────────────────┘  └─────────────────────────────────┘  │
│                                                                          │
│  ┌──────────────────────────────────────────────────────────────────┐  │
│  │  하단 플로우차트 (Result)                                         │  │
│  └──────────────────────────────────────────────────────────────────┘  │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

**비율**: 상단 1:1, 하단 전체
**용도**: 자동화, 품질 체계

## 5. 컴포넌트 스타일 가이드

### 5.1 Label (태그)
```
스타일: 연도 · 프로젝트 유형
토큰: --font-label (12px / 500)
색상: --color-foreground (투명도 70%)
대문자: 선택사항
```

### 5.2 테이블
```
헤더 배경: 없음 (투명)
첫 열: --color-primary (강조)
구분선: 1px solid (투명도 20%)
패딩: 16px
```

**예시**:
| 문제 | 현상 | 영향 |
|------|------|------|
| UI 불일치 | 프로젝트마다 다른 색상 | 브랜드 일관성 붕괴 |

### 5.3 타임라인 (2열)
```
레이아웃: 좌우 2열 교차
항목 간격: 16px
연결선: 2px solid --color-primary
마커: ● (8px)
```

### 5.4 성과 그리드 (2×2)
```
레이아웃: 2행 2열
그리드 간격: 16px
아이콘: ▸ (primary color)
제목: --font-title
설명: --font-body-sm
```

### 5.5 플로우차트 (가로)
```
방향: 좌 → 우
박스: 둥근 모서리 (8px)
화살표: → 또는 ─────→
배경: --color-primary-100
텍스트: --font-body-sm
```

### 5.6 IA 트리 구조
```
├─ 부모 노드
│  ├─ 자식 노드 1
│  └─ 자식 노드 2
└─ 형제 노드
```

## 6. 페이지 구성 템플릿 (9페이지)

| 장 | 제목 | 레이아웃 | 핵심 요소 |
|----|------|----------|-----------|
| 1 | 커버 | 2컬럼 (이미지:텍스트) | 타임라인, 성과 그리드 |
| 2 | 문제 정의 | 1:1 | 테이블, Before/After |
| 3 | 솔루션 개요 | 1:2 | 원칙 목록, 구조도 |
| 4 | 핵심 기능 | 1:3 | 단계별 설명 (6스텝) |
| 5 | 기술 선택 A | 1:2 | Why + How 플로우 |
| 6 | 기술 선택 B | 상하 분할 | 비교, 위험 플로우 |
| 7 | 자동화 | 상하 분할 | 문제/해결, 플로우 |
| 8 | 품질 관리 | 상하 분할 | 프로토콜 단계 |
| 9 | 결과물 | 1:2 | 스크린샷, IA 트리 |
