# 디자인 시스템 포트폴리오 상세 계획

> 스타일 가이드: [portfolio-make-guide.md](./portfolio-make-guide.md) 참조

---

## 페이지 구성 (총 9페이지)

| 장 | 제목 | 핵심 내용 |
|----|------|----------|
| 1 | 커버 | 프로젝트 요약 + 타임라인 + 성과 |
| 2 | 문제 정의 | 왜 이 프로젝트가 필요했나 |
| 3 | 솔루션 개요 | 어떤 생각으로 해결하려 했나 (전체 구조도) |
| 4 | /setup-design | 핵심 명령어 상세 - 구성요소와 작동 방식 |
| 5 | 토큰 배포 | 왜 CDN인가? |
| 6 | 컴포넌트 배포 | 왜 npm인가? |
| 7 | 자동 업데이트 | 왜 Dependabot + Auto-merge인가? |
| 8 | 품질 체계 | 왜 Generation Protocol인가? |
| 9 | 문서 사이트 | 최종 아웃풋 - UI로 구현한 결과물 |

```
│ | 업데이트 누락 | ... | ... |       │ (일관된 디자인)                      │
```

### 콘텐츠

| 문제 | 현상 | 영향 |
|------|------|------|
| UI 불일치 | 프로젝트 A는 `#3B82F6`, B는 `#2563EB` 사용 | 브랜드 일관성 붕괴 |
| 설정 복잡 | 토큰 복사, 패키지 설치, 규칙 문서화 7단계 | 신규 프로젝트 온보딩 30분+ |
| 업데이트 누락 | 중앙에서 토큰 변경해도 각 프로젝트 수동 반영 | 버전 파편화 |
| 컴포넌트 중복 | 같은 Button을 프로젝트마다 새로 구현 | 개발 리소스 낭비 |

### 스타일
- 테이블: 헤더 배경색 없음, 첫 열 Primary 컬러, 얇은 구분선
- 비율: 1:1

```
│            │    즉시 반영 가능               Hook 동작 확인                 │
│            │                                                                │
│            │ 03 Copy Rules              06 Complete                        │
│            │    design-rules.md를            설정 완료 메시지               │
│            │    .claude/skills/에 복사       사용 가이드 안내               │
│            │    Generation Protocol 적용     문서 사이트 링크               │
└────────────┴────────────────────────────────────────────────────────────────┘
```

### 콘텐츠

| Step | 제목 | 설명 |
|------|------|------|
| 01 | Install Package | @geniefy/ui 설치, node_modules에 추가 |
| 02 | Add CDN Link | index.html에 tokens.css CDN 추가, 즉시 반영 가능 |
| 03 | Copy Rules | design-rules.md를 .claude/skills/에 복사, Generation Protocol 적용 |
| 04 | Register Hook | PostToolUse Hook 등록, AI 코드 생성 시 검증 |
| 05 | Verify Setup | 토큰 로드 확인, 컴포넌트 import 테스트, Hook 동작 확인 |
| 06 | Complete | 설정 완료 메시지, 사용 가이드 안내, 문서 사이트 링크 |

### 스타일
- 각 스텝: 제목 + 3줄 설명 (무엇을 + 어떻게)
- 비율: 1:3
