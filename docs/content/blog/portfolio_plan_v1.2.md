# 포트폴리오 프레젠테이션 시스템

> 프로젝트 경험을 웹 슬라이드로 공유하는 시스템

---

## 개요

프로젝트 포트폴리오를 **프레젠테이션 형태**로 웹에서 볼 수 있도록 구현했습니다.
PDF 없이 URL만 공유하면 바로 확인 가능합니다.

## 디자인 시스템 포트폴리오 (9장)

AX 조직을 위한 디자인 시스템 구축 및 양방향 동기 자동화

| 장 | 제목 | 내용 |
|----|------|------|
| 1 | 커버 | 프로젝트 요약 + 타임라인 + 성과 |
| 2 | 문제 정의 | 프로젝트마다 다른 UI, 반복되는 설정 |
| 3 | 솔루션 개요 | 중앙 집중형 토큰 + 양방향 동기화 |
| 4 | /setup-design | 명령어 실행 시 작동 로직 |
| 5 | 토큰 배포 | CDN 배포 + symlink 동기화 |
| 6 | 컴포넌트 배포 | npm 버전 관리 |
| 7 | 품질 체계 | Generation Protocol 4단계 검증 |
| 8 | 자동화 체계 | 양방향 동기화 플로우 |
| 9 | 문서 사이트 | 50+ 페이지 문서 구조 |

**핵심 성과:**
- 프로젝트 초기 설정: 30분 → 1분 (`/setup-design`)
- 버전 업데이트: 수동 → 자동 (Dependabot + Auto-merge)
- 코드 품질: Generation Protocol로 토큰 미사용 차단

## CRO 실험 포트폴리오 (7장)

비개발자의 랜딩페이지 운영 자동화

| 장 | 제목 | 내용 |
|----|------|------|
| 1 | 커버 | 프로젝트 요약 + Before/After |
| 2 | 시작 | Claude Code로 직접 제작/배포 |
| 3 | 정량 분석 자동화 | cro_analyzer 시스템 구축 |
| 4 | 분석 적용 | 20기 랜딩페이지 데이터 기반 개선 |
| 5 | 정성 데이터 수집 | Exit Intent 팝업 구현 |
| 6 | 완성된 시스템 | 정량 + 정성 통합 분석 체계 |
| 7 | 회고 | 교훈과 향후 계획 |

**핵심 성과:**
- 분석 시간: 2시간 → 2분
- 이탈 원인 파악: 추측 → 직접 수집 (Exit Intent)
- 개선 적용: 1-2주 → 당일

## 사용 방법

### 네비게이션

| 동작 | 방법 |
|------|------|
| 다음 슬라이드 | `→` 또는 `Space` 또는 버튼 클릭 |
| 이전 슬라이드 | `←` 또는 버튼 클릭 |
| 홈으로 | `Esc` |

### 특징

- **반응형**: 데스크톱/태블릿 대응
- **프로그레스 바**: 상단에 진행률 표시
- **숨김 URL**: 메인 사이트에서 직접 접근 불가 (URL 공유 필요)
