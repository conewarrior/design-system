# AX 디자인 시스템

> 팀 공용 디자인 토큰과 컴포넌트를 중앙에서 관리하고, 프로젝트에 자동으로 배포하는 시스템

---

## 문제 상황

| 문제 | 결과 |
|------|------|
| 프로젝트마다 색상/간격이 다름 | 브랜드 일관성 붕괴 |
| 매번 토큰 파일 복사 | 수동 작업, 버전 불일치 |
| AI가 생성하는 코드 품질 들쭉날쭉 | 하드코딩 색상, 이모지 아이콘 등 |
| 컴포넌트 중복 개발 | 시간 낭비 |

---

## 해결책: 중앙 집중형 디자인 시스템

**design-system 저장소**
- tokens.css (CDN 배포)
- components/ (npm 배포)
- design-rules.md (AI 품질 규칙)

⬇️ **/setup-design 명령어** (1분 만에 프로젝트 설정 완료) ⬇️

**각 프로젝트에 자동 적용**

## 토큰 시스템 (tokens.css)

### 포함 항목

| 카테고리 | 예시 | 개수 |
|---------|------|------|
| 색상 (Neutral) | --neutral-50 ~ --neutral-1000 | 14단계 |
| 색상 (Primary) | --primary-500 (#f97316) | 11단계 |
| 색상 (Extended) | Blue, Teal, Cyan, Purple, Magenta, Orange | 6팔레트 |
| 색상 (Semantic) | Success, Warning, Error, Info | 4팔레트 |
| 간격 (Spacing) | --spacing-1 (4px) ~ --spacing-96 (384px) | 4px 단위 |
| 라디우스 | --radius-sm (2px) ~ --radius-full (9999px) | 6단계 |
| 타이포그래피 | --font-size-xs ~ --font-size-9xl | 13단계 |
| Shadow | --shadow-xs ~ --shadow-2xl | 7단계 |
| Z-index | --z-index-dropdown (100) ~ --z-index-toast (800) | 9단계 |
| Motion | Duration, Easing | 14개 |

### 다크모드 지원

.dark 클래스 추가 시 자동 전환
- --color-bg-default: var(--neutral-900)
- --color-text-default: var(--neutral-50)

## /setup-design 자동화

### 실행 결과

1분 실행으로 다음 항목 자동 설정:

| 항목 | 설명 |
|------|------|
| npm 패키지 | @design-geniefy/ui 설치 |
| tokens.css import | 프로젝트 엔트리에 자동 추가 |
| CLAUDE.md | 디자인 규칙 섹션 추가 |
| Hook 설정 | design-rules 자동 로드 |
| 검증 스크립트 | lint-design-rules.sh |
| Dependabot | 자동 업데이트 + 자동 머지 |

### Before / After

| 지표 | Before | After |
|------|--------|-------|
| 프로젝트 초기 설정 | 30분 | **1분** |
| 토큰 버전 업데이트 | 수동 | **자동** |
| 코드 품질 검증 | 리뷰어 의존 | **자동화** |

## Generation Protocol (AI 품질 관리)

### 4단계 검증 프로세스

**1. Pre-check**
- design-rules.md 로드 (Hook 자동 실행)
- 토큰 목록 확인

**2. Generation**
- 토큰만 사용 (하드코딩 금지)
- SVG 아이콘만 사용 (이모지 금지)
- Shadow 최소화 (Modal/Dropdown/Toast만)

**3. Post-check**
- lint-design-rules.sh 자동 실행
- 위반 발견 시 수정 요청

**4. Contribution**
- components/ 변경 시 자동 PR 생성

### 금지 패턴 자동 탐지

| 위반 | 예시 | 탐지 |
|------|------|------|
| 하드코딩 색상 | #fff, rgb(0,0,0) | 자동 |
| 이모지 아이콘 | 체크, X, 경고 이모지 | 자동 |
| 텍스트 아이콘 | x, +, 화살표 문자 | 자동 |
| 하드코딩 radius | border-radius: 8px | 자동 |
| 불필요한 shadow | Card에 shadow 사용 | 자동 |

## 양방향 동기화

### 업로드 (프로젝트 → 중앙)

1. 프로젝트에서 컴포넌트 작성
2. Hook이 변경 감지
3. auto-contribute.sh 실행
4. design-system 저장소에 PR 생성
5. 리뷰 후 머지 → npm 배포

### 다운로드 (중앙 → 프로젝트)

1. design-system 새 버전 배포
2. Dependabot이 PR 자동 생성
3. CI 통과 시 자동 머지
4. 프로젝트에 최신 버전 적용
